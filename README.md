# Task Manager API

REST API для управления задачами.

## 🚀 Технологии

- Java 23
- Spring Boot 3.3.5
- Maven
- JUnit 5

## 🏃 Как запустить

1. Открой проект в IntelliJ IDEA
2. Запусти `TaskManagerApplication`
3. Открой в браузере:
    - http://localhost:8080/api/hello
    - http://localhost:8080/api/health
